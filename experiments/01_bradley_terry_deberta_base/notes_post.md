# DeBERTa-v3-base + Bradley–Terry — предварительный вывод

Сабмишен v3 получил public log loss **1.26893**. У baseline на ручных признаках **1.04598**, разница **+0.22295**. Итоговый OOF v3 пока не восстановлен. Источники: [README](../../README.md) и [сабмишен](../../submissions/exp1/llm-finetuning-bt-deberta.ipynb).

## Как обучалась модель

[Kaggle-ноутбук](notebooks/kaggle.ipynb) использует общий DeBERTa-энкодер для пар «промпт + ответ A/B». Разность скалярных наград определяет предпочтение A/B, а обучаемый порог δ задаёт вероятность ничьей. В сохранённом коде пять фолдов (0–4), четыре эпохи, CLS-пулинг, предел 1024 токена и fp16. Learning rate энкодера, головы и δ составляют соответственно `5e-5`, `1e-4` и `2e-5`. В [истории проблем](problems.md) для отдельной группы δ предложено `2e-6`. Локальная копия Kaggle-ноутбука без логов обучения.

В ноутбуке задан resume из `checkpoint1/res`. Для завершённых фолдов он использует уже сохранённые веса, а для продолжаемого фолда восстанавливает состояние оптимизатора и scheduler. Поэтому по ячейке `CONFIG` нельзя восстановить фактическую историю learning rate каждого из пяти весов.

## Что подтверждается

- **Ранний reward collapse** описан в `problems.md`: на одном раннем чекпойнте почти нулевой разброс наград на 400 примерах, а `val_log_loss` двух фолдов около 1.0967. Для весов сабмишена v3 этот диагноз пока не проверен. Гипотеза о слишком быстром δ остаётся причинным объяснением из заметок. При почти нулевом `d` порог может подстроить вероятность ничьей под частоту класса, но сам этот факт не доказывает, что высокий LR δ вызвал коллапс.
- **Качество около 1.31 на валидации** видно в сохранённом [Colab-логе](notebooks/colab.ipynb): фолд 1 после возобновления завершил вторую эпоху с `val_log_loss=1.3066` и `δ=0.1636`. Это подтверждает слабый результат на конкретной эпохе. Для вывода о плато и его причине нужна история эпох и конфигураций. Происхождение весов v3 из этой сессии пока не установлено.
- **Заниженная вероятность ничьей** видна в выводе сабмишена: на трёх открытых тестовых строках усреднённый прогноз близок к `[0.45, 0.45, 0.10]`. При `d≈0` формула модели даёт `P(tie)=tanh(δ/2)`, поэтому при `δ=0.2` даже максимальная вероятность ничьей около 10%. Это согласуется с малым порогом, но среднее по пяти весам и трём строкам не определяет δ каждого фолда или разброс `d` на всей валидации.
